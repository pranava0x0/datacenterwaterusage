## Method and limits

Run `python3 scripts/uat_site.py --out docs/uat-2026-11-02-final.json` in an environment with the project's dependencies, Playwright and Chromium. The script serves an immutable snapshot of `pages/` through a local gzip-capable `ThreadingHTTPServer`. The assigned port is read from the server. File hashes identify the tested build. A rebuild must precede the run; the script does not regenerate pages. [Script](../scripts/uat_site.py)

Each viewport starts with a fresh browser context. Click clocks begin in an in-page capture listener and end when the expected DOM state is asserted. The figures exclude human reading and typing, and do not claim full pixel presentation time. Each flow has one sample per viewport, so the results describe this run rather than a stable percentile. The cold load is measured separately from the idle wait. [Script](../scripts/uat_site.py)

Chrome DevTools Protocol supplies JS heap and task/script duration. Ten-second idle traces count Paint, layout and animation events. Summed trace durations can include nested work; they are not interchangeable with renderer task time. Total browser memory, GPU memory, compositor-process CPU, dropped frames, production CDN transfer and field INP remain unmeasured. Browser-transfer bytes include the browser's header estimate; gzip file size estimates compressed body size. [Script](../scripts/uat_site.py)

The gate checks real DOM geometry, missing content, script errors, elapsed interaction/load budgets and the existing raw-file limits. It derives tab coverage from the rendered navigation and rejects an unrecognized tab. Known-bad browser fixtures deliberately introduce overflow, excessive depth and a missing target. A separate test rejects a running offscreen animation. [Gate tests](../tests/test_uat_site.py)

The initial baseline run required corrections to the test: a project example's selected state is preserved when its text changes, so the edit flow now explicitly changes the state; action-only rows have no content-length assertion. The saved baseline was collected again after both corrections. Its offscreen-animation verdict was then derived from the recorded profile without changing any measurements.
